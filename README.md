# Orellana in Amazonia

Carte interactive de l’expédition de Francisco de Orellana sur l’Amazone, **1541–1542**.

Chaque point est une étape documentée (lieu, dates, motif de l’arrêt, ce qui s’y passa). On avance en touchant un marqueur, ou avec **Destination suivante**.

Les faits suivent principalement la *Relación del nuevo descubrimiento del famoso río Grande* de Gaspar de Carvajal. Les seigneuries riveraines (Aparia, Machiparo, Omagua, Amazones) sont des reconstitutions : Carvajal compte en lieues, pas en latitudes.

## Lancer en local

```bash
npm install
npm run dev
```

Ouvre [http://localhost:8080](http://localhost:8080).

## Stack

React 19, TanStack Start, Tailwind CSS v4, Leaflet.
